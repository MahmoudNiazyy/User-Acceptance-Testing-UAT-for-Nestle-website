# README.md for User Acceptance Testing (UAT) of Bakers Dry Adult Beef & Vegetables Product Detail Page

## Project Title
# User Acceptance Testing (UAT) for Bakers Dry Adult Beef & Vegetables

## Description
This document outlines the User Acceptance Testing (UAT) performed on the product detail page for **Bakers Dry Adult Beef & Vegetables** dog food from Purina. The goal of this testing is to ensure that the page meets user requirements, functions correctly, and provides a satisfactory user experience.

- [Testing Objectives](#testing-objectives)
- [Test Environment](#test-environment)

## Testing Objectives
- Verify that the product detail page displays accurate information.
- Ensure that all functionalities (e.g., add to cart, product details) work as intended.
- Assess the overall user experience, including navigation and visual design.

## Test Environment
- **URL:** [Bakers Dry Adult Beef & Vegetables](https://www.purina.co.uk/dog/dog-food/product-bakers-dry-adult-beef-vegetables)
- **Browsers Tested:** Chrome, Firefox, Safari
- **Devices Tested:** Desktop, Mobile (iOS and Android)
